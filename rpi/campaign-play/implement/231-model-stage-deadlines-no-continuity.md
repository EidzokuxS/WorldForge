# Task 231 — Model-stage deadlines without synthetic continuity

## Outcome

Campaign Play no longer converts an exhausted or rejected model path into a deterministic continuity scene. A player action now publishes a new proper scene only after the Narrator artifact is accepted. If the authorized model attempts fail, the durable operation remains failed or the turn remains interrupted and the existing recovery surface reports that truth.

## Experience contract

- Actor: the Campaign Play player.
- Surface: the rendered Campaign Play scene and action controls.
- Trigger: submit one player action while Z.AI is configured for the playable roles.
- Observable outcome: Judge, Game Master, required Actor work, and Narrator each receive their own bounded operation window; a new scene is shown only from an accepted model artifact.
- Forbidden outcome: no deterministic prose or scene may be manufactured to make a failed model path look successful.
- Preserved behavior: one authorized same-model recovery remains allowed; late/stale writes remain fenced; existing historical deterministic-continuity saves remain readable and are never rewritten.

## Diagnosis

The final r193 and r194 endurance lanes did not demonstrate reliable model narration. Their durable evidence recorded 47/60 and 59/60 deterministic-continuity scenes respectively. In r194, Narrator attempts comprised 31 immediate `stage_budget_exceeded` results, 28 local `stage_timeout` results, and one accepted attempt. The immediate failures were application-created: player actions shared a `submittedAt + 115,000 ms` control target, so earlier Judge, Game Master, and Actor work could consume the Narrator's entire window before Narrator started. Later calls that did start were aborted by the remaining local deadline.

Fresh scalar diagnosis separated three more product-owned failures from provider silence:

- r195: Game Master proposal generation returned after about 62 seconds, but its Grounding Reviewer inherited the same 90-second stage window and was aborted after roughly 27 seconds. Recovery repeated the defect: the proposal took about 84 seconds and left roughly five seconds for review.
- r196: Judge returned structured responses on both attempts. Attempt 1 omitted the redundant possession quantity; attempt 2 was switched to tool mode and omitted the top-level disposition. Both were local contract/recovery-policy rejections, not absent responses.
- r197: Actor Replanner proposal generation returned after about 85 seconds, but its Grounding Reviewer inherited the same 90-second stage window and was aborted after roughly five seconds.

The provider answered in every one of these diagnosed cases. The application either starved a later stage, rejected a harmless omission, or changed the recovery output mode.

## Implementation

- Removed the player-action-wide 115-second deadline from external model-stage execution.
- Single-call stages use a 180-second operation window. Reviewed Game Master and Actor Replanner stages use 365 seconds, while each proposal and Reviewer provider call has its own 180-second SDK timeout under the same outer cancellation signal.
- Opening now uses the reviewed 365-second external model-stage window. Player-action Judge remains on the single-call 180-second window; reviewed Game Master and Actor Replanner stages remain on 365 seconds. Initial and automatic Narrator operations keep their existing 180-second narration windows.
- Judge accepts omitted possession quantity as the existing semantic default of one and keeps automatic structured-output mode on recovery instead of switching to tool mode.
- Removed all production writers for `control_budget_continuity` and `deterministic_continuity`; the old read/validation path remains solely for historical persisted rows.
- Exhausted Judge/Game Master paths remain interrupted, exhausted Narrator paths remain failed, and no proper scene is inserted for either condition.
- Z.AI OpenAI-compatible requests now send `User-Agent: claude-cli/2.1.218 (external, cli)`. Other providers retain their existing headers.
