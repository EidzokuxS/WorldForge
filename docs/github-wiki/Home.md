# WorldForge wiki

WorldForge is a text RPG sandbox where you create a world, make a character, and play inside a campaign that keeps track of places, people, memories, factions, secrets, and consequences.

It plays closer to a local tabletop campaign than a plain chat window. The game can improvise, but it also records what happened, respects what your character can know, and lets the world push back.

## What this wiki explains

This wiki is a map of what WorldForge can do and how the main systems work in plain language. It skips deep developer details, but it does explain the machinery: how a world is created, how a player turn is judged, what gets remembered, and how the narrator fits into a larger runtime.

During play, `/chat/action` uses `gameplay-cycle-runtime`. The old V1/V2 gameplay runtime paths are archived or removed from the active tree, so normal play does not need env flags to pick a runtime.

## What you can do

- Create a campaign from a short idea, crossover, genre pitch, or original premise.
- Review the generated world before playing.
- Create or import a player character.
- Explore locations, talk to people, investigate mysteries, fight, hide, bargain, travel, or make trouble.
- Watch important NPCs and factions react over time.
- Use saves/checkpoints when a scene goes sideways.

## The core promise

You are one person inside a world.

If you leave a room, the people in that room can still matter. If you lie, the game should treat it as a claim. If a secret exists, the narrator needs a player-visible path before revealing it. If you make a risky choice, the result should become part of the campaign instead of being forgotten next turn.

That is the point of WorldForge.
